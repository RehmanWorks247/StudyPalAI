`spoken-digits.wav` contains the first four seconds of the Vosk API project's
[English example recording](https://github.com/alphacep/vosk-api/blob/4ab9821510b488efb7740094714a130bd3545e90/python/example/test.wav)
(Apache-2.0). The automated lecture test uses it as a synthetic microphone.

`lab-notes.docx`, `lab-slides.pptx` and `observations.csv` are synthetic classroom materials for batch import tests. The Word document was written by python-docx 1.2.0 and the slide deck by python-pptx 1.0.2. The deck's presentation order differs from its slide filenames.

`printed-lab.png`, `printed-lab.jpg` and `scanned-lab.pdf` each contain one synthetic line of printed English, rasterized with Pillow. The PDF contains only its raster image.
